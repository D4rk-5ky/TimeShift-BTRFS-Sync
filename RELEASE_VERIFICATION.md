## Limits

Live SSH using the user's btrfs-sync account, live passwordless sudo policy, live Timeshift inventory/mounting, backup transfers, restoration and deletion were not tested. No real snapshot mutation or notification deployment was performed. Python 3.11 and full MQTT/PyInstaller dependency installation/build were not exercised. The preserved executable is still 0.1.84; run/install the current Python source or rebuild for this command.

Listing changes no permissions or sudoers. Actual absent/corrupt/unreadable files can still leave metadata unknown. Timeshift --list may perform its normal temporary mounting and operational logging; the app performs no explicit mount, snapshot mutation, transfer, cleanup, state/lock/log write or notification. Concurrent changes can affect observations; Complete confirms payload presence, not restore eligibility. Space is filesystem-wide, shared between roots on the same filesystem and not guaranteed Btrfs receive capacity.

Extract this release into a fresh directory to avoid retaining obsolete files from an older checkout. Earlier ZIPs and the uploaded original are unchanged.
